## Como usar

1. [Baixe o **NexBoost.exe**](https://github.com/AndreiCardozo/nexboost-download/raw/main/NexBoost.exe) (versão 0.1.1, 4,5 MB).
2. Abra com dois cliques. Não precisa instalar.
3. Se o Windows SmartScreen avisar (o arquivo não tem assinatura digital), clique em **Mais informações** → **Executar assim mesmo**.

Requer Windows 10 ou 11 com o WebView2 (já vem no Windows 11).

## O que ele faz

- Mostra o valor atual e o novo, o risco e como desfazer **antes** de qualquer mudança.
- Guarda backup de tudo o que altera; o que é apagado vai para a Lixeira.
- Nunca desativa Defender, Firewall, SmartScreen ou Windows Update.
- Funciona offline, sem telemetria e sem conta.
